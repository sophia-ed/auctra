## 1. Access model (verified, important)

| Endpoint | Auth | Result |
|---|---|---|
| `GET /v2/price_feeds?query=…` | **keyless** | 200, returns usable feed metadata + IDs |
| `GET /v2/updates/price/latest?ids[]=…` | **API key required** | `401` without a key (observed) |

Implication for Auctra: **feed discovery is keyless; live price updates require `PYTH_API_KEY`.** The application must degrade gracefully when the key is absent (discovery + cached/manual observations) rather than failing.

Two further access paths noted during the audit, both legitimate and worth supporting:

1. **On-chain Pyth push feeds on Solana** — zero-key. A third-party Stocklana entry (`equitycurve`) reports parsing all 46 sponsored shard-0 receiver accounts and decoding the 134-byte `priceUpdateV2` layout (discriminator, write authority, feed id, price, conf, exponent, publish times, ema, posted slot). This is an on-chain route and must be verified against current Pyth docs/types before use — do not assume the byte layout from a third party.
2. **Pyth Pro (subscription)** — the Stocklana Pyth track prize includes 3 months of Pyth Pro (1,200+ equity feeds). Pyth Pro is a *push/stream* product (see §2) and is the source of `marketSession` / `feedUpdateTimestamp`.

### 2.1 Carried-forward price semantics (directly supports Section 14)

Verbatim from the docs:

> If `feedUpdateTimestamp` is equal to the update's `timestampUs`, the price was generated as part of this update. If `feedUpdateTimestamp` is earlier than `timestampUs`, the price is the most recent available price, **carried forward** from the time indicated by `feedUpdateTimestamp`, not generated at the current update time. Consumers should always rely on `feedUpdateTimestamp` to understand the freshness and origin of the price.

Therefore Auctra must:

- compute `age = now − feedUpdateTimestamp` (never `now − timestampUs`),
- classify `FRESH / AGING / STALE / UNKNOWN` from that age,
- optionally surface a distinct `CARRIED_FORWARD` note when `feedUpdateTimestamp < timestampUs`.

### 2.2 Market session (Section 16)

Use Pyth's `marketSession` when available. Do **not** reconstruct session from local browser time. The discovery endpoint also exposes a `market_hours` object (`is_open`, `next_open`, `next_close`) and a per-exchange `schedule` string, useful as a secondary signal.

## 3. Discovery response shape (off-chain, keyless)

Each item from `/v2/price_feeds`:

```json
{
  "id": "<64-hex feed id, no 0x>",
  "market_hours": { "is_open": false, "next_open": 1790170200, "next_close": 1790193600 },
  "attributes": {
    "asset_type": "Equity",
    "description": "TESLA INC / US DOLLAR",
    "display_symbol": "TSLA",
    "nasdaq_symbol": "TSLA",
    "quote_currency": "USD",
    "schedule": "America/New_York;...",
    "symbol": "Equity.US.TSLA/USD"
  }
}
```

Note the **market-session-adjacent** distinction: `Equity.US.*` are regular-hours feeds (`is_open` follows NYSE hours) while `Equity.Index.*` are described as *"PYTH PRICE IN USD FOR <X> 24/7"* (`is_open: true` around the clock). Auctra should prefer the 24/7 `Equity.Index` feed when modeling the onchain/private clock, and the `Equity.US` feed when modeling the public regular-session clock.

## 5. Mapping to the Auctra reference model (Section 14/15)

```text
hermes item.id                -> ReferenceObservation.feedId
attributes.symbol             -> ReferenceObservation.symbol
attributes.asset_type         -> MarketAsset.assetType (display only)
price mantissa + exponent     -> ReferenceObservation.price (Decimal)
confidence + exponent         -> ReferenceObservation.confidence (Decimal)
exponent                      -> ReferenceObservation.exponent
market_hours / Pro session    -> ReferenceObservation.marketSession
feedUpdateTimestamp (Pro)     -> ReferenceObservation.feedUpdateTimestamp  (freshness source of truth)
publish/observed timestamp    -> ReferenceObservation.publishTime
```

`confidenceBps = confidence / price × 10,000` (Section 15). Never treat `bestBidPrice` / `bestAskPrice` as core logic unless explicitly enabled and labeled **EXPERIMENTAL**.
